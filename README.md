# Monte

Monte is a market intelligence platform that monitors public web sources including news, Reddit, X, and LinkedIn to deliver competitive intelligence, market signals, and customer pain insights to businesses.

## Reddit Integration

Monte uses the Reddit API for read-only keyword and entity monitoring across public subreddits. No write operations are performed.

## Stack

- Python / FastAPI
- Supabase (Postgres)
- PRAW / Reddit JSON API
- NewsAPI
- Claude API (summarisation and signal classification)
